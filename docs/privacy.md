# 隐私与数据生命周期

MarkdownMint 的设计目标是让文档正文只在导出链路中流转。

- 浏览器预检只计算字数、标题和资源数量；草稿仅保存在当前浏览器的 IndexedDB；
- 点击生成后，Markdown、上传资源和配置才发送到 Renderer；
- 日志记录任务 ID、阶段、耗时、错误码、页数、资源规模聚合值和产物校验和，不记录正文、令牌
  或远程 URL 查询参数；
- 产物按保留期清理，下载完成后客户端不自动永久保存副本；
- 配置 `RENDERER_DATA_DIR` 后，任务 JSON 会在保留期内保存源 Markdown、上传资源和导出配置，PDF/HTML
  与首页 PNG 也会落在同一持久卷；到期 sweep 删除任务记录和对应产物；
- 生产下载地址使用短期 HMAC 签名，签名密钥不进入任务日志或浏览器草稿；
- 远程资源代理默认关闭，服务端不能访问宿主凭据、任意本地路径或内网地址；
- 当前 Web 站不启用行为分析或广告追踪。若未来增加匿名指标，必须先完成隐私评审并更新本页。

生产部署应使用 HTTPS，配置 `NUXT_PUBLIC_RENDERER_URL` 指向受控 Renderer，并设置精确的
`RENDERER_CORS_ORIGIN`。请不要把包含机密、个人信息或未授权内容的文档发送到未经审查的实例。
持久卷及其备份必须使用加密、最小访问权限和与保留期一致的删除策略；备份介质的生命周期也属于
Renderer 数据生命周期，不能因为任务已过期而继续无限保留。
