## 发布决定

只有所有自动化门禁和人工签字完成、发布阻塞项为零、上一稳定版本回滚已验证，才能勾选：

- ☐ 批准创建 release tag
- ☐ 批准生产部署

任何一项为否都应记录原因、责任人和下一步，不得用 fallback 样张或本地通过替代缺失验收。
