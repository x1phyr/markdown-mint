# 产品定义与 v1.0 边界

## 一句话定位

MarkdownMint 将已经完成的 Markdown 铸造成设计精美、结构稳定、可直接交付的 PDF 与独立 HTML 文档。

## 用户问题

Markdown 作者通常已经在 VS Code、Obsidian、Typora、Cursor 或其他工具里完成写作，但最后交付时仍要面对：

- 浏览器打印结果不稳定，分页、页眉页脚和目录难以控制；
- GitHub/编辑器样式适合阅读源码，不像正式报告或出版物；
- 中文字体、代码块、表格、数学公式和图表难以同时排好；
- 每次制作报告都要复制 CSS、修改模板和手工修 PDF；
- HTML 依赖原网站，不能方便地离线发送或归档。

MarkdownMint 只解决这一步，不重做用户已有的写作工具。

## 目标用户

1. 需要交付技术方案、架构文档和 API 指南的工程师；
2. 需要发布 PRD、项目总结和业务报告的产品与运营人员；
3. 使用 Markdown 写教程、长文和电子刊物的作者；
4. 需要把 Markdown 批量纳入自动化发布流程的团队。

## 核心工作流

```text
导入 Markdown
    ↓
检查文档摘要与诊断
    ↓
浏览预先生成的主题样张
    ↓
选择主题和少量导出参数
    ↓
生成完整 PDF 或 HTML
    ↓
查看结果摘要并下载
```

主题样张由真实渲染管线和标准 fixture 生成，但不根据用户内容实时刷新。用户文档只在点击生成后执行完整编译、资源处理和分页。

## v1.0 必须交付

### 输入

- 上传、拖入或粘贴一个 Markdown 文档；
- 单次输入上限、资源上限和支持格式有明确提示；
- Frontmatter 可填写标题、副标题、作者、日期和语言；
- 显示字数、标题、代码块、表格、图片、公式和图表数量；
- 返回可定位的警告和错误，不静默丢失内容。

### 内容能力

- CommonMark 与 GFM；
- 标题、段落、列表、任务列表、链接、引用、分隔线；
- 表格、脚注、代码块、语法高亮；
- 本地和远程图片的受控处理与图注；
- KaTeX 数学公式；
- Mermaid 图表，隔离渲染为清理后的 SVG；
- Callout、手动分页和目录控制等 MarkdownMint 扩展；
- 中文/英文混排和常见长内容边界情况。

### 主题

- Technical Mint；
- Minimal Report；
- Editorial Serif；
- 每套主题包含 Manifest、Design Tokens、Content CSS、Screen CSS、Print CSS；
- 每套主题提供封面、正文、复杂内容至少三张自动生成样张；
- 主题对统一 fixture 通过视觉回归和分页检查。

### 导出

- PDF：A4/Letter、纵向/横向、三档边距、封面、目录、页码、可选页眉页脚；
- HTML：单文件、自包含样式、离线可打开、无服务端运行依赖；
- 结果页提供实际第一页缩略图、页数、大小、主题与下载入口；
- 同一 `CompiledDocument` 同时服务 PDF 与 HTML，禁止双份编译逻辑。

### 非功能要求

- 不信任 Markdown、HTML、SVG、远程资源、字体和渲染器输出；
- 渲染任务在受限工作区中执行，拥有超时、内存、CPU、文件和网络策略；
- 输入、日志和产物有明确保留期，默认不永久保存用户文档；
- Web 核心流程符合 WCAG 2.2 AA 的键盘、语义和对比度要求；
- v1.0 支持简体中文和英文界面；
- 关键 API 有可观测性、追踪 ID、结构化日志和可操作错误码。

## 明确不进入 v1.0

- 实时 Markdown 预览、左右分栏编辑器和滚动同步；
- 根据用户内容实时切换主题预览；
- 多文件项目、文件树、版本历史和在线协作；
- 用户上传任意 CSS、字体或执行脚本；
- 可视化拖拽排版、封面设计器和低配 Canva 能力；
- DOCX、EPUB、PPTX 等额外输入输出；
- 账号、团队空间、计费和模板市场；
- 浏览器端完整分页引擎。

## v1.0 成功标准

发布候选版本必须同时满足：

- 官方综合 fixture 的 PDF 和 HTML 生成成功率为 100%；
- 在基准环境中，20 页普通文档 P95 生成时间不高于 15 秒；
- 100 页压力 fixture 在限制内完成或返回明确的资源错误，不造成服务失稳；
- 三套主题不存在已知 P0/P1 视觉缺陷；
- 所有 P0/P1 功能有自动化测试，核心包行覆盖率不低于 80%；
- 安全威胁模型完成评审，高危依赖漏洞和未解决高危发现为 0；
- 无障碍、中文排版、主流桌面浏览器和离线 HTML 验收完成；
- 从全新环境按照 README 可完成安装、测试、构建和本地启动。

这些指标是发布门槛，不是增长目标。匿名产品指标应在确认隐私策略后单独定义。
