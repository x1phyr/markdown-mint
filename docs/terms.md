# 服务条款（预发布草案）

本文是 MarkdownMint 进入正式服务前的预发布草案，不能替代部署方所在地适用法律要求的最终条款。正式公开服务前，维护者或部署方必须完成法务审阅，并补充运营主体、联系方式、适用法律和争议解决地。

## 服务范围

MarkdownMint 用于把用户已经完成的 Markdown 文档转换为 PDF 或独立 HTML。项目当前处于
pre-alpha / `v0.0.x`，公开 API、主题协议、限制和部署方式可能变化，不承诺向旧版本永久兼容。

## 用户内容与责任

- 用户保留其 Markdown、上传资源和生成内容的权利，并负责确认拥有处理这些内容所需的授权；
- 用户不得提交恶意脚本、未经授权的个人信息、违法内容，或利用服务访问第三方内网、凭据和本地文件；
- 生成结果应由用户在交付、发布或打印前自行复核，尤其是分页、字体、图表和图片；
- 反馈、错误报告和诊断应去除真实文档、令牌和其他不必要的个人信息。

## 数据与保留

浏览器草稿只保存在本地 IndexedDB。提交任务后，Markdown、资源和配置会在受控 Renderer 中短期处理；
任务、产物和缩略图按部署配置的保留期清理。生产部署必须使用 HTTPS、精确 CORS、短期签名下载地址
和受控的密钥托管。详细说明见[隐私与数据生命周期](privacy.md)。

## 可用性与限制

预发布版本不提供服务级协议、持续可用性承诺或数据恢复承诺。服务可能因资源上限、超时、浏览器、
字体、第三方依赖或维护而拒绝或中断任务；合理的错误重试不能保证恢复原始任务。

## 第三方组件

Renderer 使用浏览器、字体和其他开源组件，适用各自许可证。用户和部署方应遵守[第三方许可清单](third-party-licenses.md)。

## 变更与终止

维护者可以为安全、合规、性能或产品边界修改、暂停或停止预发布服务。重大协议变化应记录在
[迁移说明](migrations.md)与 CHANGELOG 中。

## 联系与正式版本

正式服务上线前，本页必须补充有效的隐私、支持和安全联系渠道；安全问题请先按
[SECURITY.md](../SECURITY.md) 私下报告，不要公开粘贴真实用户内容。
